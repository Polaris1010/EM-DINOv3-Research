## 本轮问题与决策

1. **来源均衡采样本身是否有效：本轮无法单独因果识别。** D1采用新SSL留出池和30k→100k续训日程，历史B100为全池100k且曾无标签接触评测图像；D1与B100差异不能只归于sampling。旧结果原样保留，首seed历史参考Dice：{'G-P0': 0.8130427360533896, 'G-B100': 0.8273065136014968}。没有擅自增加第三组训练。
2. **增加CEM是否进一步改善：** 同协议D2−D1来源等权Dice = +0.022448。这是本轮匹配对照，包含已披露的CEM原生尺寸格式适配；仅一个decoder seed，不宣称统计显著性。
3. **是否保留原有正向来源：** 逐来源开发变化见上表，Fly/HeLa/Lucchi等另见固定MB1诊断表；不是只报告总均值。MB1已参与研究决策，不能称盲测，也不用于选择配比、loss或checkpoint。
4. **是否进入局部结构一致性：** 必须同时结合内部开发和MB1逐来源结果；内部均值提升不能替代跨数据集改善证据。一个decoder seed不证明收益稳定。 本轮均到此停止，100k完成后停止，不自动D3、更长SSL或更多seed。

## 数据与证据边界

[MitoNet原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC9883049/)明确将benchmark及关联图像从CEM1.5M/CEM-MitoLab排除。因此D1/D2共同移除MitoVerse正式test、已映射validation/dev及已知MB1关联资产；D2从作者原始CEM再移除可识别的MV3留出关联集合。CEM未读取CEM-MitoLab标签。

实际池：153个MitoVerse体积、12来源、34143合法Z；CEM原包1592753图/651目录记录（640非空），排除13个可识别关联集合后1425433图/627非空集合。索引SQLite及ZIP偏移/逐成员CRC提供无损随机访问；数据与排除理由见mitoverse_pool.json、cem_pool.json。集合/volume代理不虚构独立acquisition。

未知哈希CEM集合与MV3开发图像的精确交叉关系仍UNVERIFIED。固定MV3监督协议也不因本轮改变，同来源/关联采集暴露限制继续存在；仅采用SSL留出原则并不能把完整系统结果升级成严格独立acquisition外测。自然权重的上游暴露亦未穷举。

MitoVerse保留既有512裁剪与小图reflect padding；CEM保留原生PIL RGB（通常224），不预先放大或补成512，采用同一官方RandomResizedCrop输出256/112，存在不同native FOV/插值因素，不把它们解释成纯数据数量效应。

50k仅导出留档；所有下游使用固定100k，并且两组共同40k head预算。D12_100k_checkpoint_hashes.csv提供50k/100k EMA及head路径/SHA，训练曲线、吞吐/显存和来源抽样计数保留各rank JSONL。原B100/MV1至MV5/MB1未改写。

输出：D12_100k_per_region_metrics.csv、D12_100k_source_metrics.csv、D12_100k_paired_deltas.csv、D12_100k_benchmark_per_image.csv、D12_100k_benchmark_per_dataset.csv、D12_100k_summary.json及本报告。服务终止证据和历史输入前后快照由有界控制器保存；代码/指标/Markdown由本轮收取器提交推送。
