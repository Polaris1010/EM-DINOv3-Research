# D2-Coverage：从 P0 开始的简化设计

2026-10-20，PLANNED；用户选择从 P0 重新开始。本轮只更新设计，没有启动训练。本文取代此前推荐的 30k 分支执行路线；原设计、CPU模拟和历史 D1/D2 全部保留。

## 决策

采用官方自然 DINOv3 P0，重新进行完整 100k SSL。取消恢复 30k 优化器、rank RNG、已访问集合和剩余预算补偿。直接预先确定全程集合配额，集合内按随机队列无放回遍历。

从 P0 开始解决续训状态和分段日程的复杂性，但不能消除全覆盖与历史 sqrt 集合分布之间的冲突。只运行一组新全覆盖模型，可以与历史 D2 做系统结果比较，不能把差值全部归因于覆盖率。

若目标是严格检验重复抽样的影响，建议两组都从 P0 开始，使用相同集合配额和逐位置集合序列，只改变集合内 ID 选择：有放回 vs 无放回。额外匹配对照是研究建议，不是已获授权的训练，也不是启动单组工程试验的前置条件。

## 简单配额，不做中途切换

保留原数据池：CEM N=1,425,433 张、627 collections；MitoVerse 153 volumes、34,143 个合法 Z ID。保留排除清单，不读监督标签。

保持 global batch 48、100k steps、seed 0。复用已有确定性数据域序列，约 50:50；已验证该序列全程有 M=2,398,767 个 CEM 槽位，其余 2,401,233 个为 MitoVerse。MitoVerse 槽位及其采样规则不变。

设集合大小为 n_i，p_i=sqrt(n_i)/sum_j sqrt(n_j)，安排：

q_i = n_i + largest_remainder_i((M-N) p)

其中 M-N=973,334。最大余数法以固定集合 ID 打破并列，保证整数配额之和为 M。每集合先获得足以遍历一次的容量，剩余容量按 sqrt 权重分配。

把包含 q_i 个集合 i 的槽位列表，用固定独立 seed 全局打乱，再填入 CEM 槽位。整个 100k 使用这一条序列，不设覆盖结束后的阶段切换。

- 全覆盖组：每个集合维护确定性洗牌队列，走完再洗牌；因为 q_i>=n_i，100k 完成时每张保留图像至少访问一次。
- 可选匹配组：同一个槽位选中同一个集合，但集合内均匀有放回抽 ID。

集合、数据域的顺序和次数可在两组之间完全相同；图像重复次数本来就是研究变量，不能声称逐图分布也完全相同。增强策略和随机种子保持一致，图像尺寸不同仍可能导致实际裁剪坐标不同。

忽略整数舍入，新的集合概率为：

q_i/M = (N/M)(n_i/N) + (1-N/M)p_i

N/M 约 59.42%。约 59.42% 容量由图像数比例决定，40.58% 由 sqrt 权重决定。大集合相对历史 sqrt 分布获得更多容量，这是全覆盖的代价；全程随机交错避免连续大块数据占据某个阶段，却不消除总配额偏移。

## 实现与验收范围

当前 `src/d2_coverage/` 模拟针对 30k→100k，不是本方案的实现。其 A67.05%、B81.46%、C100% 以及 69236 步覆盖结果不能标成新 P0 方案的模拟结果。本轮没有重复模拟。

后续若获实施授权，最少改动是新增 step0 全程配额计划生成器，复用已有按全局索引读取 ID 的接口，独立接入新训练入口；原入口和历史配置不修改。模拟与实际 loader 必须消费同一计划。不得用旧 C 计划直接启动此方案。

必要 CPU 验收：配额和正确、全池覆盖、域序列不变、匹配组集合序列相等、三 rank 重排及中断恢复一致。按全局 sample index 定位固化计划，checkpoint 保存计划 SHA 和已消费位置，避免 worker 预取改变恢复结果。训练验收沿用既有 smoke。

这些是尚未执行的验收要求；当前只有数学覆盖保证，未宣称新方案通过运行测试。

## 成本与停止规则

历史 D2 完整 100k SSL 合计约 20.72 小时，使用物理 GPU1/2/3；据此估计每个新 run 约 21 小时、约 62 GPU-hours。相比从 30k 接续，单组增加约 6.3 小时。新的 I/O 分布可能改变吞吐，此处不是实测新耗时。

若实施严格匹配两组，顺序训练约 42 小时 SSL，另加每组约 51 分钟的首 seed head，以及开发/MB1 推理时间。只运行全覆盖一组则成本减半，但结论边界如上。不自动扩展成两个训练任务。

全程 int32 ID 计划约 19.2 MB；一条 CEM 集合计划用 int32 约 9.6 MB，可提前确定，不需要恢复 30k seen bitmap。沿用此前 checkpoint 保留策略，SSL 每组建议预留约 30 GB，head/预测另计；历史权重不覆盖。

完成既定 100k 和固定下游读出即停止。不因肌肉单组成绩调权重，不自动延长步数、搜索配比或加入 D3。如果整体与逐来源表现没有明确价值，结束这一采样方向；单组结果不用于证明覆盖率的因果贡献。
