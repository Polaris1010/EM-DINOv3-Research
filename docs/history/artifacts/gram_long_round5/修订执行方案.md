# 第五轮修订执行方案（2026-09-15）

本轮保留 Gram 长程锚定，先进行成对实验，判断它是否缓解继续训练引起的密集特征退化，以及是否超过原始 P1。获得改善后再决定下一轮扩展。

| 实验 | GPU | 初始化 | 改动 | 预算 |
|---|---:|---|---|---|
| G | 3 | P1 EM125k | 官方 Gram 权重在前 1000 步由 0 余弦升至 2 | 总计 30,000 SSL 步 |
| C | 1 | 同一 P1 | Gram 权重恒为 0，仍计算相同教师分支 | 同样 30,000 SSL 步 |
| X1 | 2 | P1 + 每个 seed 的共享初始 head | 解冻最后 4 个 block | seed 0/1/2，各 10,000 步 |

G/C 使用同一预生成采样、增强、掩码序列，每一步核对实际输入张量哈希链。SSL seed 固定为 0；下游三 seed 是 head 训练重复，不能解释为三次独立 SSL 复现。

原始 P1 文件的 SHA256 校正为 `53f759c7019f8753d9d18b52aa79168b51b7480466934df47f46bc3d5f696524`。P1 只有教师导出，本轮初始 AdamW 为新建，不能称作原训练优化器续跑。本轮生成的完整 checkpoint 保存 student、EMA、Gram teacher、优化器、损失缓冲、随机状态、调度位置和采样位置，并验证第 10→11 步恢复一致性。

官方参数采用 normalized/image-level/all tokens，global 256、local 112×8、Gram teacher 512、teacher 无颜色扰动，EMA 0.999，WD 0.04，AdamW (0.9,0.99)，clip 30，layer decay 0.98，patch LR multiplier 0.2。保留现有 ViT-L 与兼容 heads，避免换架构。虚拟迭代从 1,000,000 起，因此官方 LR 和温度预热已结束，teacher temperature 为 0.07；这不代表 P1 已实际训练百万步。

先尝试 batch 16（基础 LR 1.5e-5）；若显存不足，停止全部本轮进程，双方一起从 P1 改为 batch 8（基础 LR 1.0606601717798212e-5）并重做检查。不能仅调整一侧。500 步检查计入总 30,000 步，恢复时不重置优化器或调度。

锚点初始为 P1，目标是保护其继续训练中的表征，而非恢复到一个已证明更优的早期教师。10k 和 20k 更新锚点会影响后续训练；30k 的更新仅为终止记录，不会改变本轮已完成的训练。

数据清单保留 7 个具名 JRC 来源共 144,384 张图像，排除所有 MitoEM、Lucchi、匿名和不明确裁剪。对照现有划分检查已知来源身份；P1 的历史预训练暴露无法清除，因此本轮仍属开发性评估，不能宣称密封的未见测试。

X1 修正原 forward 的整段 no_grad：仅最后 4 个 block 开启梯度，逐层检查有限梯度与权重变化，其他 encoder 参数冻结。head/gate LR 保持 R4 实际值 1e-4，最后 4 层 LR 3e-6；沿用 N2、batch 8、crop 256、原采样序列、初始 head、损失与调度。模型输出保存重载后必须一致。

10k/20k checkpoint 使用 seed 0 的冻结 encoder 探针，只查看 validation；30k 使用 head seeds 0/1/2。全部 head 训练预算 10k，按既定 validation 选择 head，最终固定测试仅评估一次。中间探针在 SSL 完成后排队执行，以保证不根据中间结果调整 G/C。X1 三 seed 依次训练并评估。

判定同时报告 G−C 与 G−P1：若 G>C 而两者都低于 P1，只能说明缓解退化。保留 Gram 的预设门槛为源等权 Dice 平均提升至少 0.005、至少 2/3 head seeds 为正、至少 4/6 测试来源改善且 precision/recall 无崩溃；逐来源展示，避免单来源主导结论。

全局守护仅使用 GPU 1–3，核对现有网站进程身份与 HTTP 健康。出现未知 GPU 进程、内存/温度/磁盘等异常时停止本轮所有已登记进程，尽力保存后退出，不等待成对里程碑。禁止触碰 GPU 0 或结束其他用户进程。

本轮执行到 G/C 长程及其探针、X1 三 seed 结束后停止，提交结果审核，不自动扩展 X2/X3 或权重搜索。

资源保护补充：已知网站进程出现过约 1.8 GiB 的短暂显存增加，随后恢复至约 458 MiB，HTTP 仍为 200。原先固定约 256 MiB 波动阈值导致第三次短测保护性退出。修正为核对进程身份、持续 HTTP 健康、共享卡至少 2 GiB 剩余显存、网站增加不得超过 4 GiB；启动须无其他任务且至少 18 GiB 可用。短测观察到本轮 SSL 分配峰值约 10.3 GiB，含缓存约 13 GiB；该阈值为网站保留空间，未知进程仍立即停止。

依据：[DINOv3 论文](https://arxiv.org/html/2508.10104v1)、[官方 Gram 配置](https://raw.githubusercontent.com/facebookresearch/dinov3/main/dinov3/configs/train/dinov3_vit7b16_gram_anchor.yaml)、[MedDINOv3 论文](https://arxiv.org/html/2509.02379v1)。Gram 的作用假设是限制继续训练时 patch 关系退化；是否提升本任务分割成绩，须由 G/C 及 P1 的配对评估确认。
