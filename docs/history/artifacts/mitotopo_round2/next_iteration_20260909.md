**优先级 1：建立足够可靠的比较协议。**

现有 17 个图块只作回归检查，不能用于最终宣称超越。从已审计的 specimen 建立训练、验证和封存测试划分；同 specimen 的 ROI、相邻切片和重复数据必须同组。旧验证集已经反复用于探索，不再改名为独立测试集。追查自然图像、EM 预训练与 MitoNet 已知训练来源的重叠；无法排除的部分明确标为重叠风险，不宣称严格未见域。

先选尺寸有界、含完整实例及可信标注范围的连续子体做实例诊断，之后再扩展完整体积。排除未采集或无有效原图的区域，并区分未标注与真实背景。保留无前景但有效的图像，避免人为提高精度。预测与标签保持同一物理尺度；单方向和多方向 3D 协议分开比较。

主指标为累计 PQ、实例 F1、split/merge 与 Recall，Dice 为辅助。记录每个 specimen 的结果、吞吐和峰值显存；最终结果采用多个随机种子和 specimen 层面的不确定性估计。

**优先级 2：同一个实例解码器，比较编码器。**

| 组 | 编码器 | 解码器与训练协议 |
|---|---|---|
| A | 自然图像 DINOv3 | 相同的语义＋中心热图＋yx offset 头 |
| B | EM-v2、未做 Gram | 同 A |
| C | 已核验的 Gram 检查点 | 同 A |
| D | 无 Gram 等步数续训 | 同 A，若预算不足则明确缺少此控制 |

A 的 storage tokens 等结构与 EM-v2 不同，应使用各自可严格加载的骨干，统一输出特征层和解码接口，不能静默丢键。先冻结编码器检验表征；再只解冻末尾少数块，避免同时改动全部网络。解码器统一采用 MitoNet 官方配置中的损失权重和后处理参数作为起点；结构适配与非官方训练参数逐项记录。

训练集内采用前景／随机图块混合采样，候选起点各占一半，并记录实际前景占比；不根据验证结果挑选训练图块。先通过单个有标注图块过拟合检查，再检查多图块训练的前景召回与损失，随后按共同预算训练至验证趋势稳定。200 步只作短测，不能作为充分训练的胜负依据。

**优先级 3：在有效基线上逐项增加改进。**

1. 实例边界监督：目标包括两个相邻非零实例之间的边界；上一轮仅有语义前景轮廓，不能监督粘连实例分离。
2. 2.5D：共享编码器读取相邻切片，融合后预测中心切片。切片间隔依据 z 向物理分辨率确定，不能默认所有数据的相邻层具有相同距离。
3. z-affinity：监督相邻层实例连接，使用有界块与明确的跨块合并规则，测量 3D split/merge。
4. 域增强与尺度条件：只从训练域生成灰度、对比度、尺度及有限的 Fourier 增强，验证图像不参与训练。每次只增加一种因素。

先做实例头，再做实例边界，再做 2.5D；暂不继续堆频域门控。若固定编码器对照中 Gram 没有稳定收益，先检查 anchor 质量、训练域覆盖及训练时长，不凭 SSL 总损失下降认定下游提升。官方 Gram 长训和微型 batch 的适配不是完全相同的训练条件；训练步数相同也不等于看过同样多样本。

验收条件：候选在封存 specimen 测试上，以同一协议超过 MitoNet 的主实例指标，关键域召回不出现不可接受的退化，且结果可复现。任何短测小幅变化都不宣布“超越”。资源规则沿用前轮：GPU0 禁用、不影响其他进程、开跑前检查、资源异常仅停止自己的作业。
