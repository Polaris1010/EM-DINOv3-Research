## 协议与解释

- Encoder 全部冻结；相同 decoder 初始状态、随机种子 20260907、fold-0 划分和 3000 步 decoder 训练预算。最终原始网格完整 3D 体积推理，沿用相同四翻转 TTA 和 decoder 选择规则。
- Dice/HD95/NSD 使用此前核验过的 MedDINOv3 官方测试入口。NSD 容差为 1.0，当前 spacing=(1,1,1)，距离数值按 voxel 等效单位解释；真实 EM 物理尺度未校准。
- 均值为体积等权平均；SD 为体积间样本标准差（ddof=1），不是随机种子标准差。CMCC n=3，CMCT n=2，单种子，不作统计显著性声明。
- 续训完整恢复 100k 状态，新增 50k 使用基础学习率 1e-6。此结果不能等同于从头采用 150k 余弦调度的实验。
- 当前为验证集冻结表征测量，SSL 数据覆盖与最终独立测试集需要另行审计；尚未建立与 MitoNet 的直接性能结论。
- 均值、SD、逐体积对应关系和差值已独立复算检查。完整精度数据见同目录 JSON 与 CSV。

## 本轮判断与下一步建议

- 两个数据集的平均 Dice、NSD 均下降，平均 HD95 均改善；150k 没有显示出一致的分割质量提升。暂时优先保留 100k 为主基线，150k 保留作对照。
- CMCC 三个体积的 Dice 均下降，主要下降集中在 crop110（约 -0.01970）。该体积召回率从 0.70063 降到 0.66915；其 HD95 改善不能代表漏检减少。CMCT 肝脏体积略有提升，肾脏体积下降。
- 不建议立即延长到 200k。可以先补 125k 的相同冻结评测，检查是否存在中间较优 checkpoint；必要时用额外匹配随机种子复核当前差异。
- 随后优先建立与官方 MitoNet 的同体积分割对照、训练数据覆盖审计及漏检/边界错误分析，再选一个机制做短程验证。P 继续暂缓，当前不启动新模块长训。
- 这次实验仅说明原最小学习率下增加 50k 的收益有限，不能据此证明最优收敛、过拟合或已超过 MitoNet。
