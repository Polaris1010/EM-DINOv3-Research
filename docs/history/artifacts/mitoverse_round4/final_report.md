## 七项结论

1. P1 相对 P0 的预注册描述性规则：True。P0存在结构转换影响，不能解释为纯预训练因果效应。
2. P2 相对 P1 的规则：False。
3. 逐来源改善见下表和 source_metrics.csv。
4. 没有足够证据确认严格 SSL 未见来源，不能证明完全未见域收益。
5. 建议进入下一轮分阶段微调：P1，本轮不自动启动。
6. 全来源分组避免同来源跨split；P2筛选数据OpenOrganelle排除。历史预训练曝光证据存在不确定性；conrad23在第一轮smoke中曾用于5个验证patch，不能称为历史上从未查看过的封存测试。见split_audit.md和pretraining_exposure.csv。
7. 根据来源差值和失败案例决定是否分阶段解冻；若P2证据不足停止额外SSL搜索，使用P1。
