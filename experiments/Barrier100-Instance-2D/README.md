# Barrier100-CEM 冻结语义分支与二维实例头

研究任务使用 CEM-MitoLab 真实实例监督，在已训练的 Barrier100-CEM 上新增二维实例 ID 输出。用户将首轮预算从 10,000 更新为 40,000 步，正式评测使用第 40,000 步。系统在 192.168.203.98 上运行，训练限定物理 GPU 2。

## 训练

复用 seed 20261014、batch 4 的原训练数据序列，40,000 步使用 160,000 个裁块。通过原实验的 fit.primus 构建模型，校验 encoder 和 Primus 40k checkpoint 的 SHA256，原语义路径全程 eval 且关闭梯度。实例头读取 Primus 第二个上采样阶段的四分之一分辨率特征，回归一张中心热图及两个中心偏移分量。中心目标为 sigma 6 像素的高斯，偏移以 32 像素为单位。对触及图边、裁剪边缘或忽略区的实例，屏蔽其像素上的实例损失。中心使用加权 MSE，偏移仅在可监督实例像素上计算 L1。AdamW 固定学习率 0.0001。所有学习参数仅属于实例分支。

10k 处保存第一次训练的模型及 AdamW 状态，后续从相同状态及数据索引续训到 40k。首次从零复现可运行 finish.sh，实际运行的两段模式以初始进程 PID 为参数。服务端目录为 /opt/data/3_117/tanghr/codex/barrier_primus_instance_20261120，依赖同级 mix_mitolab_mv_20261118 的接口及其既有 Python 环境。SEMANTIC_RUN 可指定该接口目录。

## 推理与比较

沿用原 sliding 实现、256 窗口、128 步幅、TTA 关闭及语义阈值。每个 tile 的中心与偏移场映射回原图，重叠区用非零 Hann 权重融合，在整图上执行一次中心检测和像素归属。固定中心阈值 0.1，9 像素最大值窗口。若整图有语义前景但无中心，则使用八连通域并记录 fallback。相邻切片的实例 ID 各自独立。

evaluate_head.py 使用相同语义前景的八连通域分组作为配对参照。实例指标复用既有二维 empanada 评分接口和阈值口径；AP50/AP75 为该实现的匹配指标。MB-1 与 CEM validation 读取原实例 ID，MV3 仅在 instance_proofread 区域计算实例指标。语义复现核对历史 TP/FP/FN/TN，每个评价单元的第一张图另做原始路径与新增路径的逐像素比对。记录接触实例对中分别获得不同主预测 ID 的数量；该统计需结合 PQ/AP 一起解释。示例图从左至右为原图、实例 GT、语义预测、连通域参照、实例头预测，配套 NPZ 保留完整预测 ID。

运行 test_interface.py 可核实真实图像的语义一致性，以及相接实例、截断实例和忽略区的训练目标。训练写出 progress.json、训练日志及可恢复 checkpoint。最终输出 metrics_40000.csv、evaluation_complete.json 和 scores_40000 下的逐项记录、图片与预测。
