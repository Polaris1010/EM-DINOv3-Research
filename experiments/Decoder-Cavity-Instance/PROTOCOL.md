# Frozen C1 Barrier100k decoder comparison

- Both arms use the original C1 Barrier100k official EMA checkpoint and the same frozen ViT-L/16 layers 5, 11, 17, 23, CEM-only batch-four draws, batch 4, 40,000 updates, seed 20261014 and historical AdamW schedule. Smoke measurements are excluded from the formal 40,000 steps.
- Both start from byte-identical shared decoder and foreground head weights. Four 1x1 projections are averaged, followed by two 3x3 residual blocks and four bilinear/convolution upsampling steps. A shallow 16/32-channel image path is fused at 128 and 256.
- A uses BCE-with-logits and soft Dice on binary foreground. B adds 2-pixel inner rings/contact lines and per-crop, per-instance normalized EDT. Ignored pixels are excluded from losses. The two auxiliary losses each have weight 1; within the distance term background weight is 0.05. EDT and rings use the available instance extent within the training crop.
- Shared inference geometry is native-grid 256 tiles with reflect padding. Primary results use Gaussian sigma 64 / stride 120; uniform stride 128 is the companion setting. No resampling or phase TTA.
- B chooses one global (seed threshold, boundary threshold, minimum area) triple from an eight-point grid on at most six deterministically selected CEM validation images per collection by collection-equal PQ, then AP75 and lexicographic tie break. The same triple is used for both window policies and all other datasets. B watershed is restricted to the foreground/boundary core. Semantic Dice uses foreground alone.
- For instance comparison, CC always uses 8-connectivity on the thresholded foreground and prior Empanada metric definitions, with PQ and AP50/AP75 aggregated per image within source and then equal across sources. Previous legacy results retain their recorded evaluation geometry.
- Evaluation is on all 2595 MB-1 views, all 1424 CEM validation views, all 38 MV3 dev regions, and the 20 HQ-5nm fields shared with phase experiments. MV3 instances are scored only on data with a proofread instance contract. HQ-5nm has no GT. The 12 error panels replicate the previous MB-1 case list, with supplementary Fly brain views.
